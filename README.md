# Cyberpunk Portfolio

A modern, responsive portfolio website with a striking visual aesthetic inspired by Persona 5. Built with React, Tailwind CSS, and Framer Motion.

## Features

- **P5 Inspired Design**: Bold colors, halftone patterns, and dynamic UI elements.
- **Responsive Layout**: Optimized for desktop and mobile devices.
- **3D Background**: Features a Three.js / React Three Fiber interactive scene.
- **Interactive Animations**: Smooth scroll animations and page transitions.
- **Mini Game**: "Phantom Reflex" built-in mini game for user engagement.
